# Nyay Veda ⚖️

An AI-driven, web-based legal case management system designed to organize legal proceedings and optimize judicial workflows. 

🚀 **[View Live Application](https://nyay-veda-hub.vercel.app/)**

## ✨ Features

* **Comprehensive Case Management:** Store, manage, and organize critical legal case information in a centralized hub.
* **Smart Judge Allocation:** Intelligently assign cases to presiding judges based on their specific legal expertise (case type) and current schedule availability.
* **Real-Time Status Tracking:** Monitor the lifecycle of active cases with dedicated frontend views for status updates.
* **Dynamic Categorization:** Efficiently filter and sort legal documents and cases by legal domain for quick retrieval.

## 🛠️ Tech Stack

* **Frontend:** React 🔵⭐
* **Backend:** Node.js & Express
* **Database:** MongoDB 🍃
* **Intelligence:** AI Integration

## 💻 Local Development

To run this project locally, ensure you have Node.js and npm installed (using nvm is recommended).

**1. Clone the repository:**
```bash
git clone [https://github.com/Arpit2301/nyay-veda-hub.git](https://github.com/Arpit2301/nyay-veda-hub.git)
cd nyay-veda-hub
npm i
npm run dev
```
